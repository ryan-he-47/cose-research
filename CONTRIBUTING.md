# Contributing

This is an active research prototype. Issues that include a minimal example,
the configuration, software versions, and the observed output are useful.

Keep representation, sampling, and metric changes explicit. Preserve source
attribution and distinguish byte reconstruction, conditional prediction, and
free-running generation when reporting language results. Include the recipe
and evaluation population with any numerical comparison.

Run the CPU checks described in the README for changes to packaging or imports.
Model changes should include a check of the affected numerical path. Training
and checkpoint downloads are separate operations from the source smoke check.
